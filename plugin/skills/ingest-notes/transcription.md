# Transcription rules

The transcript is evidence. It records what is on the page, not what the writer meant.

- Number lines per page: `L1`, `L2`, …, so the plan can cite `p2 L4-6`.
- Keep the original line breaks, abbreviations and spelling. Don't expand "w/" or fix "Thornwik".
- Mark an uncertain word as `[?best guess]`, and an unreadable one as `[illegible]`. Give alternatives as `[?Brackwater|Blackwater]`.
- Mark crossed-out text as `~~text~~`. Crossed-out text is usually a retcon, so carry it into the plan as a possible conflict.
- Mark marginalia, arrows and inserts as `[margin: …]`, `[arrow from L3 to L7]` and `[insert after L5: …]`.
- Describe drawings and maps in one line: `[sketch: tavern floor plan, three rooms, cellar door marked X]`.
- Flag GM-only cues as `[GM]` at the start of the line. Cues include "DM only," "secret," "don't tell," "!!" and a circled or boxed note. Also flag a different ink color the writer clearly uses for private notes.
- For printed adventure pages with handwritten annotations, transcribe the annotations and only enough of the printed text to anchor them: `[printed: "The door is locked (DC 15)"] [note: "they kicked it in, Brannoc hurt"]`. Don't reproduce published adventure text wholesale. Summarize it.
- Put dice rolls, initiative lists and HP tallies under an `### Ephemera` heading. Keep them for the session log, but never extract them as lore.
